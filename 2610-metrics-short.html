02How we measure

Define the task first. The instrumentation follows these five and nothing else — we do not record every click.

Principles
  • Record only what answers a question — about 6–10 events per journey
  • Reuse existing logs first, add only the gaps
  • One journey end to end, verified, then reuse
How we start
  1. Agree with the pod lead what a finished task meansUX + Pod lead
  2. Confirm what existing data covers and what is missingEngineering + data
  3. Run Calculation and Data Explorer end to endEngineering + QA
  4. Produce the first improvement listUX + PO

The same definition works for every use case. This is a template, not a one-off report.

03Business value

The same engineering effort, spent where it matters more

This is not a one-off output; it comes from a loop that keeps running. Instrumentation produces data, data decides what to fix first, and the same number then shows whether it improved. One full turn of that loop is what we accept as done.
